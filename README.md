# Tarapacá Explore

Mockup interactivo de una red de señaléticas QR para el turismo en la región de Tarapacá, Chile.

Mapa Folium con puntos de interés, navegación por regiones y flechas direccionales hacia puntos ocultos que se revelan al hacer zoom.

## Características

- Mapa Leaflet/Folium con 5 puntos principales (Iquique, Pisagua, Humberstone, Pica, Mamiña)
- 15 puntos secundarios que aparecen al hacer zoom (*zoom ≥ 13)
- Flechas direccionales que guían hacia puntos verdes cercanos
- Selector de idioma ES/EN
- Diseño responsive (mockup de celular)

## Tecnologías

HTML, CSS, JavaScript · Folium · Leaflet.js · CartoDB tiles
